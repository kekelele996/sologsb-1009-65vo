# 教材无障碍改写工作台

面向教材编辑和特殊教育内容团队的无障碍改写、自动检查、审校与导出工具。项目预置科学教材章节示例并包含真实的待处理问题。

## 功能

- **原稿侧与改写侧两份数据各自持有**：原稿侧只存出版社发布的版本（界面只读），改写侧存编辑写的无障碍文本、改写原因、改写结论、审核状态、批注、术语表与版本快照。
- **接入新版原稿时逐块对接**，不依赖段落位置：
  - 接得上（文字未动，即使段落挪动）：沿用原改写，含「已通过」状态；
  - 原稿文字动过：退回待改写并标记「原稿已改」，原「已通过」作废，旧改写、旧原因进入历史留档对照；
  - 原稿去掉的块：整条改写挪到「留档区」，带当时原文快照，不进入导出；
  - 新加的块：按待改写进入。
- **失败恢复**：新原稿解析为空时两侧数据一律不动；接入结果先写阶段日志再分两侧提交，源侧或改写侧写入失败后可按侧重试，编辑已写内容不受影响。任一侧数据读不出来只重建该侧。旧版（schema 1，原稿改写混装）数据首次启动自动升级，原因、状态、批注、版本快照全部保留。
- 导入 TXT、Markdown 章节文本；识别 Markdown 标题、图片和单行链接。
- 检查标题层级跳跃、图片替代文本缺失、链接文案不明确、长句和术语不一致。
- 将复杂段落按标点和语义拆为较短的易读表达，并统一术语表中的固定表达。
- 为每个内容块记录改写原因、改写结论及待改写、已通过、需修改状态；原稿改动后审核状态自动作废。
- 添加批注、回复和解决批注。
- 阅读预览可在普通模式和高对比、大字号辅助模式间切换。
- 以编号列表展示读屏软件从 H1 到正文、图片和链接的阅读顺序。
- 保存最多 10 个版本快照（按原稿块内容编号），并排比较旧版和当前无障碍文本。
- 撤销/重做、自动保存、离线继续编辑。
- 导出完整无障碍 HTML：包含 `lang`、跳转正文链接、语义标题、图片 `alt`、描述性链接、键盘焦点样式和屏幕阅读器可读结构；留档块不进成品。
- 键盘操作：`J`/`K` 跳转问题，`E` 生成易读版本，`1`/`2` 切换预览模式，`Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Shift+Z` 重做，`Ctrl/Cmd+S` 保存版本。

## 技术栈

- Astro 7 + TypeScript
- Shoelace Web Components
- 原生 DOM/CSS 与浏览器 `localStorage`
- 静态 HTML 构建、nginx 容器部署

## 开发

需要 Node.js 22.12 或更高版本。

```bash
npm install
npm run dev
```

## 检查、测试与构建

```bash
npm run check
npm run test
npm run build
npm run preview
```

`npm run build` 会先执行 Astro 类型/内容检查，再生成 `dist/` 静态产物。
`npm run test` 用 Vitest 跑两侧对接、按侧重试与旧数据升级的纯逻辑测试（共 19 个用例）。

## Docker

容器内 nginx 监听 `80`，宿主端口按根端口映射为 `10009`。

```bash
docker build -t sologsb-1009 .
docker run --rm -p 10009:80 sologsb-1009
```

访问 `http://localhost:10009`。

## 数据说明

原稿与改写分两个 `localStorage` 键保存（`sologsb-1009-source-v2`、`sologsb-1009-rewrite-v2`），任一侧损坏只重建该侧；接入新版原稿的阶段日志为 `sologsb-1009-ingest-journal-v2`。旧版键 `sologsb-1009-accessible-textbook-v1` 会在首次启动时自动升级。导出的 HTML 是独立文件，不依赖后端，但演示图片使用内嵌 SVG；接入真实教材时应替换为可访问的正式图片地址并复核替代文本。
